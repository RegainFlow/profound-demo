# Exercise 07: Session Mining Flywheel

Start from `demo-6-hooks`. Teams create durable rules from opinions instead of evidence, which makes skills and docs drift into process overhead.

Fix by mining a prepared session log, identifying repeated corrections, and using `skill-spotter` to decide whether the artifact should become a rule, skill, doc, or nothing.

Harness lesson: the harness improves from observed review pain. Mine evidence, promote only what recurs, and keep retirement criteria visible.
