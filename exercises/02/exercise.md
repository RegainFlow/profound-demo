# Exercise 02: Linear Ticket To Scoped Product Change

Start from `demo-1-foundation`. A real prepared Linear ticket can become a broad vibe-coded change if Codex starts from a task title instead of a scoped contract.

Fix by pulling the prepared ticket from Linear during the workshop, using it as intent, asking Codex for a plan, constraining scope, implementing one product improvement, and verifying it with a focused test.

Harness lesson: the loop is ticket to plan to narrow diff to self-review.
