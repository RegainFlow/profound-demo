# Session Mining Template

Run after several Codex sessions or PR-review threads.

Prompt:

```text
Find repeated human corrections. For each, decide whether it belongs as:
- deterministic rule
- local AGENTS.md instruction
- reusable skill
- docs update
- no durable artifact

Only recommend durable artifacts with evidence, an owner, and a retirement condition.
```

Acceptance bar:

- Repeated pain.
- Clear owner.
- Small artifact.
- Verification path.
