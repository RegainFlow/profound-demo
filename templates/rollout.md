# Four-Week Rollout Template

## Week 1

- Pick one workflow.
- Add root and local AGENTS.md.
- Run deterministic checks locally.
- Use Codex first-pass review on a small PR set.

## Week 2

- Add Linear/GitHub context through approved Codex app connectors.
- Configure daily PR/task digest as a Codex-native automation.
- Track stale reviews.

## Week 3

- Mine sessions and PR comments.
- Add one deterministic rule.
- Add one skill with an owner.

## Week 4

- Review override logs.
- Adjust the risk matrix.
- Keep human gates explicit for customer-facing work.
