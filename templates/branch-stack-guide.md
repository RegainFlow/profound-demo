# Branch Stack Guide

Use branches as demo checkpoints, not as permanent product branches.

1. Keep `main` as the polished, green destination.
2. Build `demo-0/bad-state` as the messy runnable start.
3. Add one lesson per branch: foundation, tests, architecture rule, feedback rule, JSON preview/PR gate, hooks, flywheel.
4. Do not force-push over an existing remote checkpoint without explicit approval.
5. Verify each branch before pushing it.
