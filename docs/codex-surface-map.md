# Codex Surface Map

Use each Codex surface for the work it is best suited to.

| Surface | Workshop Use | Profound Fit |
| --- | --- | --- |
| Local CLI/IDE | Plan, implement, test, inspect diffs | Steerable and compatible with autonomous engineers |
| GitHub PR review | First-pass review, severity ordering, human routing | Shortens review without removing human gates |
| Linear integration | Ticket-to-agent handoff and status context | Matches the move toward Linear as source of truth |
| Codex app automations | Daily digest, stale review monitor, context cleanup | Native Codex app setup, not repo scripts or product dashboard panels |
| Browser/Playwright | UI verification and visible regressions | Keeps design-sensitive work explicit |
| Worktrees | Parallel tasks without branch collisions | Useful as AI raises PR throughput |
| Subagents | Specialized verifier/reviewer passes | Keeps review and implementation contexts separate |
| Approved app/connectors | Live context from GitHub, Linear, logs, docs, analytics | Lets agents use systems instead of pasted context |
