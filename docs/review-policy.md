# Review Policy

Codex can shorten repetitive review, but it does not replace human judgment.

- Agent-gated: deterministic rule changes, small internal refactors, focused bug fixes with tests.
- Human-on-contract: public contracts, dependency changes, cache behavior, generated reports.
- Human-mandatory: customer-facing UI, brand/design intent, security, privacy, data-loss, and irreversible operations.
- Codex review findings should be severity-ordered and diff-scoped.
