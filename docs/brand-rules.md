# Brand Rules

The design system is the brand boundary for this demo.

- Put reusable colors, spacing, radius, and primitive behavior in `frontend/src/design-system/`.
- Feature code should compose primitives such as `Button`, `Card`, `Badge`, `Table`, and `MetricCard`.
- Do not add raw color literals, inline styles, or one-off visual treatments in feature folders.
- Customer-facing layout, color, and report-copy changes require explicit human review.
